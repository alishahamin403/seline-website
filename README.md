# Seline — Website

Marketing site for **Seline**, an AI life-productivity iOS app — *your life, in context*.

Seline unifies calendar, email, notes, receipts, and location into one context-aware assistant: grounded Q&A over personal history, receipt scanning with spend tracking, location memory, and AI journal recaps.

Live: https://seline-website-three.vercel.app

## Stack

- HTML / CSS / JavaScript
- Hosted on Vercel

## The app behind the site

The Seline iOS app is built with Swift and Xcode, backed by Supabase (Postgres + Google Auth), orchestrating OpenAI and Gemini models for chat, extraction, and summarization.
